\section*{Data and Code Availability}
All code, the pre-registration file, prompts, cached model responses, generated tables and figures are available at \url{https://github.com/wijayasekarageyashmithadilshan-dot/objectgraph-agent}. Running \texttt{bash reproduce.sh} regenerates every structural result, and the agent tables can be rebuilt offline from the cached responses. DevBench is publicly available and is used at commit \texttt{\DevBenchCommit}.
